🏗️ How it works

Daily pipeline — same rails for every AI

Two GitHub Actions cron jobs drive the whole thing. Identical prompts, identical tools, identical validators across all three players — the only difference is the model behind the wheel.

⚖️ Fairness manifest

What's identical across the three players

✓Prompts — same RESEARCH_SYSTEM_PROMPT and DECISION_SYSTEM_PROMPT
✓Tools — same 5 functions, same JSON-Schema
✓Tool budget — 5 iterations max each
✓Structured output — sentinel tools for ChatGPT & Claude; native JSON mode for Gemini
✓Validators — universe, $5k min, 25% NAV cap
✓Starting capital — $100,000 paper cash each
✓Market data — yfinance, same snapshot per cron
✓Broker — Alpaca paper, market order, day TIF

The only variable is which model is reading the prompt.
